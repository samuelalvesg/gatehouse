# ADR examples

Four decisions that many teams hit. Copy the ones you adopt into your own `docs/ADR/`, and change them to fit your project. Each file follows the Nygard format: Status, Context, Decision, Consequences.

| File | Decision |
|---|---|
| `0001-status-by-definition-of-done.md` | An item is done only when every subitem is done |
| `0002-leaf-package-to-break-a-cycle.md` | Put code that needs two packages in a third, leaf package |
| `0003-code-in-english.md` | New code and comments in English; user-facing text keeps its language |
| `0004-every-change-ships-with-tests.md` | Every change ships with unit and integration tests |
