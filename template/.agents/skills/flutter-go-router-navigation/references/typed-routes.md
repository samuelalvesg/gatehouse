# GoRouter Typed Routes (reference, not the default)

Use this only if the app adopts typed routes for all features.

```dart
@TypedGoRoute<HomeRoute>(path: '/')
class HomeRoute extends GoRouteData {
  const HomeRoute();

  @override
  Widget build(BuildContext context, GoRouterState state) => const HomePage();
}

final router = GoRouter(
  routes: $appRoutes, // generated by go_router_builder
  redirect: (context, state) => resolveRouteRedirect(...).location,
);
```

Requires `go_router_builder` and a `build_runner` step. Keep the redirect decision in the pure guard, as in `SKILL.md`.
